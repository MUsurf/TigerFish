# SURF Goal detection with OpenCV and C++

## about
this project is meant to explore and integrate C++ openCV image detection into the main branch

## environment setup

This project is working as of the ISO C++ 20 standard
Every library used is part of the C++ standard library with the exception of openCV
To run this project, please make sure openCV can be accessed by the cpp file

## execution

To run the project, simply build the desired cpp file (or cpp + .h file if there exists a .h file)
