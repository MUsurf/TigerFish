Example package creation command: ros2 pkg create --build-type ament_python --license Apache-2.0 node_name --dependencies rclpy std_msgs
    - --build-type: What it is building to. Defaults to C++ one (ament_cmake or something like that)
    - --license: The license it adds. Lowkey can remove but i think good to have (im not a lawyer idk)
    - test_node: The node name
    - --dependencies: Everything after it is a dependency that the package relies on
